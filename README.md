# Sprint_6

# Автотесты для сервиса Яндекс Самокат: https://qa-scooter.praktikum-services.ru/

# Структура проекта
- tests - тесты
- pages - Page Object классы
- locators - локаторы
- conftest.py - фикстура драйвера
- urls.py - URL-адреса страниц
- requirements.txt - Зависимости проекта
- data.py - наборы тестовых данных для параметризации
- utils.py - Генерация тестовых данных

# Allure отчет
1. Сгенерировать результаты:
pytest tests --alluredir=allure_results

2. Открыть отчет:
allure serve allure_results


# Что покрыто тестами
- FAQ: проверка раскрытия ответов на вопросы
- Заказ самоката: позитивный сценарий с двумя наборами данных
- Навигация: переход по логотипу Самоката и переход на Дзен по логотипу Яндекса
